# 复制反馈工具（CopyFeedback）

一个极简的 Windows 后台小工具：按下 **Ctrl+C** 复制后，在鼠标附近显示一个 1.5 秒的小提示
「已复制」+ 内容预览，让你立刻确认复制是否成功。

- 轻量：C# + WinForms，**单个 exe，零第三方依赖**，无需管理员权限，后台常驻几乎不占资源。
- 不干扰：**不拦截、不改变**原有的 Ctrl+C；提示弹窗不抢焦点、鼠标可穿透、自动消失。
- 隐私：不写剪贴板、不记录剪贴板历史、不上传任何内容；调试日志也不含剪贴板明文。

---

## 一、功能

| 功能 | 说明 |
| --- | --- |
| 全局复制监听 | 监听 `Ctrl+C`、`Ctrl+Shift+C`（终端风格复制）、`Ctrl+Insert`，适用于浏览器、记事本、Office、聊天软件等常见应用；按键一律放行，原复制行为不变 |
| 真实复制检测 | 通过剪贴板序列号判断是否真的写入了剪贴板：**连续复制相同内容也能识别**；剪贴板被其它程序短暂占用时自动重试；没有剪贴板更新则不弹提示（避免误报；极少数来源错配见已知限制 11） |
| 「已复制」提示 | 圆角小卡片，浅色/深色主题自适应，显示「已复制」+ 内容预览；靠近鼠标、不超出屏幕工作区；约 1.5 秒后淡出 |
| 文本预览 | 折叠换行/制表符/连续空白；超长文本自动省略号截断；空白文本显示「（空白文本）」 |
| 非文本内容 | 图片显示「图片」，文件显示「文件」，其它格式显示「非文本内容」；不读取/转换大对象，避免卡顿 |
| 连续复制 | 快速连续复制只刷新同一个提示，不堆叠多个窗口 |
| 系统托盘 | 运行状态、开机自动启动开关、退出 |
| 开机自启动 | 用户级 `HKCU\...\Run`，无需管理员权限；登录时静默启动（无主窗口、无控制台） |
| 单实例 | 重复启动不会产生多个监听进程 |
| 干净退出 | 退出时卸载全局键盘钩子、移除托盘图标、停止所有定时器 |

## 二、系统要求与技术选型

- **Windows 10 / 11**（x64）。程序使用系统自带的 .NET Framework 4.8（Windows 10 1903+ 与 Windows 11 均内置）。
- 技术栈：**C# + WinForms + Win32 P/Invoke**，通过系统自带的 `csc.exe` 直接编译为单个 exe。
  - 选型理由：功能简单，Electron/Node/Python 等方案会引入较大运行时和内存占用；C# + WinForms 可以做到零依赖、单文件、低占用，且托盘、窗口、注册表、全局钩子都有成熟 API。
- 不使用任何第三方库，不需要安装运行时，不需要管理员权限。
- 平台限制的替代方案：如果运行环境不允许全局键盘钩子（例如受限的托管桌面），或系统过旧没有 .NET Framework 4.8，可以使用 Windows 自带的剪贴板历史（Win+V）、Microsoft PowerToys 等作为替代；本工具刻意不引入这些依赖。

## 五、安装与启动

### 方式 A：安装到本机（推荐，可长期使用）

双击 **`install.bat`**，它会：

1. 停止可能正在运行的旧实例；
2. 把程序复制到 `%LOCALAPPDATA%\CopyFeedback\CopyFeedback.exe`；
3. 启用开机自动启动；
4. 启动程序（无窗口、无控制台）。

安装后程序就在后台运行，系统托盘出现图标（Windows 11 默认可能在「^」隐藏区）。

### 方式 B：绿色便携

直接双击 **`dist\CopyFeedback.exe`** 即可运行。
然后在托盘菜单中勾选「开机自动启动」。此时自启动项指向 exe 当前所在路径；
如果之后移动了 exe，程序下次运行时会自动把“已失效的旧路径”修正为当前位置（若旧路径文件仍存在则不改动）。

> 关于“默认开机自启动”：通过 `install.bat` 安装时默认启用；绿色便携方式运行默认**不**会自动写自启动项（保持对系统零改动），可在托盘菜单中勾选「开机自动启动」。

### 找到托盘图标

- Windows 11：点击任务栏右侧的 **`^`**（显示隐藏的图标）可看到本工具图标；也可把图标拖到任务栏常显。
- Windows 10：图标通常在任务栏右下角通知区域。

### 退出

托盘图标右键 → **退出**。退出后会卸载键盘钩子并移除托盘图标。
（也可在命令行执行 `CopyFeedback.exe --quit`。）

## 七、使用说明与交互细节

- **触发键**：`Ctrl+C`；另外兼容 `Ctrl+Shift+C`（终端/命令行风格复制）与 `Ctrl+Insert`。带 `Alt` 的组合不会触发。
- **提示位置**：鼠标右下方约 16×20 像素；靠近屏幕右下角等边界时自动翻转到鼠标左/上方，并始终限制在屏幕工作区内。
- **显示时长**：约 1.5 秒，最后 ~125ms 淡出。连续复制会刷新内容并重新计时，不会出现多个弹窗。
- **弹窗特性**：置顶（TopMost）、`WS_EX_NOACTIVATE` 不抢焦点、`WS_EX_TOOLWINDOW` 不进入任务栏/Alt+Tab、`WS_EX_TRANSPARENT` 鼠标可穿透。
- **不写入剪贴板**：程序只读取本次复制后的内容用于预览，绝不修改剪贴板。
- **空闲开销**：没有常驻轮询；只有按下复制快捷键后才在 1.2 秒窗口内每 25ms 检查一次剪贴板序列号，随后立即停止。

## 八、命令行参数（高级/自动化）

| 参数 | 说明 |
| --- | --- |
| （无参数） | 正常启动。已有实例运行时弹出提示框后退出 |
| `--startup` | 登录自启动时使用：静默启动；若已有实例则静默退出 |

| `--disable-autostart` | 关闭开机自启动，退出码 0=成功 |
| `--autostart-status` | 查询自启动状态，退出码 0=已启用且指向当前 exe，1=未启用或路径不符 |

## 九、调试日志与隐私

- `--debug` 时写入：`%LOCALAPPDATA%\CopyFeedback\debug.log`（每次启动覆盖）。
- 异常始终追加写入：`%LOCALAPPDATA%\CopyFeedback\error.log`（超过 256 KB 自动重建）。
- 日志只包含事件与元数据（例如：复制类型、文本长度、是否截断、弹窗坐标、前台窗口句柄、检测耗时），**不包含剪贴板内容明文**。
- 程序不保存剪贴板历史、不落盘剪贴板内容、不联网上传。
- 唯一读取剪贴板的时机：检测到复制快捷键且剪贴板确实被更新后，读取当次内容生成预览。

> 注意：如果复制的是一段敏感文本（例如密码），预览会短暂显示在屏幕上——这与 Windows 自带剪贴板提示的行为一致；本工具刻意保持极简，没有提供“关闭预览”的设置项。

> 排障提示：`--debug` 每次启动会覆盖写 `debug.log`。如果已有实例在运行，请用**裸 `--quit`**（不要带 `--debug`）退出，否则会截断正在运行实例的日志。测试/排查时建议先退出旧实例，再用 `--debug` 启动。

## 十、已知限制

1. **只识别快捷键触发的复制**：`Ctrl+C` / `Ctrl+Shift+C` / `Ctrl+Insert`。通过菜单「复制」、或程序自动写入剪贴板（如截图工具保存、密码管理器自动复制）不会触发提示。
2. **检测窗口 1.2 秒**：按下快捷键后剪贴板必须在 1.2 秒内被写入。极慢的应用（拷贝超大内容）可能漏报；无剪贴板变化时不会误报。
3. **剪贴板被长时间占用**：读取会重试约 350ms；若仍被其它程序占用，本次不提示（避免误报），但不影响原复制行为。
4. **仅当前用户会话**：UAC 安全桌面、锁屏、Ctrl+Alt+Del 等系统安全界面中的复制不会被监听；注销/关机时程序退出。
5. **Windows 11 托盘折叠**：系统默认把新托盘图标放入「^」隐藏区，这是 Windows 行为，需要用户点击 `^` 查看或把图标拖到任务栏。
6. **DPI**：程序为系统级 DPI 感知，主屏高缩放清晰；多显示器且各屏缩放不同时，副屏上的提示可能由系统位图缩放（略模糊），位置也可能有少量偏差。
7. **仅支持 Windows 10/11** 且系统需自带 .NET Framework 4.8。
8. **全屏场景**：提示为 TopMost，在全屏游戏/演示中也可能短暂出现（约 1.5 秒）。
9. **单实例**：同一用户会话只允许运行一个实例；重复启动会提示“已在后台运行”。
10. **自启动路径修复策略**：自启动项指向的旧文件不存在、或路径相同但缺少 `--startup` 参数时，程序会自动修正；如果指向另一份仍然存在的程序，则尊重用户配置、不改动。
11. **极少数“来源错配”**：按下复制快捷键后 1.2 秒内，如果其它程序（剪贴板管理器、截图工具、密码管理器等）也写入了剪贴板，本工具会把它当作本次复制来提示——“已复制”是真的，但预览内容可能来自其它程序。这是序列号检测的固有边界；完全消除需要剪贴板 owner 归属校验，成本高于收益。
12. **剪贴板争用时的短暂延迟**：剪贴板被其它程序占用时，.NET Framework 的剪贴板 API 自身会重试，可能造成约 1 秒以内的 UI 响应延迟；不影响复制本身与提示结果。
13. **主题切换**：深/浅色主题在程序启动时读取，运行中切换系统主题不会立即生效（重启程序后生效）。
14. **退出后行为**：托盘「退出」或 `--quit` 退出后，全局钩子被卸载，复制不再出现任何提示；`--quit` 不会弹出窗口。

## 十三、卸载

双击 **`uninstall.bat`**：关闭开机自启动 → 退出程序 → 删除 `%LOCALAPPDATA%\CopyFeedback`。

也可手动：

1. 托盘右键 → 取消「开机自动启动」；
2. 托盘右键 → 退出；
3. 删除 `%LOCALAPPDATA%\CopyFeedback` 文件夹（以及你放到其它位置的 exe）。
